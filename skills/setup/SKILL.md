# setup

セットアップと設定変更の窓口。自分では何も書き込まず、やりたいことを判断して振り分け先に渡す。

## 振り分け

何をしたいかを一言宣言してから振り分け先へ進む（例:「CALMの設定変更として進めるね」）。違っていればユーザーがここで訂正できる。判断がつかないときだけ、やりたいことを普通の言葉で聞く。

| やりたいこと | 振り分け先 |
|---|---|
| CALMをインストールした直後で、動く状態か確かめたい・使い方を知りたい | [initial-setup](../initial-setup/SKILL.md) |
| 新しいプロジェクト・取り組みをCALMに登録したい | [project-setup](../project-setup/SKILL.md) |
| 環境変数で動作を調整したい（件数・間隔・予算など） | [env-config](../env-config/SKILL.md) |

迷う組み合わせ: インストール直後に「プロジェクトも登録したい」と言われたら、initial-setupを先に済ませてからproject-setupへ進む。
