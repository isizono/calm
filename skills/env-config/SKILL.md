# env-config

利用者が調整する環境変数を見せ、変更を `~/.claude/settings.json` の `env` に書く。一覧と既定値は手順書ではなくコードの台帳が正で、`get_config` が返す。

## 手順

1. `get_config()` を呼ぶ。`env_vars` が利用者の調整対象（`kind: "user"`）の名前・既定値・説明・現在値を持つ。`value` が `null` なら未設定で、既定値で動いている
2. 一覧を「名前 / 現在の値（未設定なら既定値）/ 説明」の表で見せ、何を変えたいかを聞く。内部調整用・緊急スイッチ・セッションごとの変数（`get_config(env_kind="all")` で見える）は勧めない。ユーザーが名指しした場合は、それが対象外の種類であることと、`settings.json` に書くと全セッションに効くことを伝えてから、書くかどうかを確認する
3. 変更内容（変数名・新しい値）をユーザーに見せ、確認を取る。確認なしで書かない
4. `~/.claude/settings.json` を読み、`env` に追記または更新する（他のキーと既存のenvは保つ）。ファイルが無ければ新規に作る。JSONとして壊さない
5. 最後に、反映には再起動が要ると案内する。MCPサーバーは常駐プロセスで、環境変数は起動時に読むため。[restart](../restart/SKILL.md) skill でClaudeが再起動する

## 注意

- 設定の書き先は `settings.json` の `env` に限る。`.mcp.json` はプラグイン利用者が持たないため使わない
- 値の型・単位は台帳の説明に従う。説明から読めないときは推測で書かずユーザーに聞く
